# Analyze manual test checklist

See the [feature guide](../../interface/inspection/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Measure a 20 × 10 × 5 mm box. Compare Bounding Box and Properties with the known dimensions and 1,000 mm³ volume.
- [ ] Overlap two solids, run Interference, then move one clear and rerun. Confirm the interference result changes.
- [ ] Use Section Analysis to reveal an interior feature. Clear the analysis and confirm the viewport returns to the full model.
