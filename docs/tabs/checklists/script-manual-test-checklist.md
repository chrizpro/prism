# Script manual test checklist

See the [feature guide](../../interface/script/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Create and save a harmless script with a distinctive printed message. Run it and confirm the message appears in the output.
- [ ] Run a copy containing a syntax error. Check that the error is visible and the editor remains usable.
- [ ] Open the scripts folder or a configured external editor and confirm the saved file is the one that opens.
