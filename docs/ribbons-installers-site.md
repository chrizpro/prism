# Ribbon consistency, installers, and documentation

## Ribbon layout

`RibbonLayoutPolicy` owns the relative section order. The shipped layout is normalized before command identities and user customizations are applied. Transform, Inspect, Select, and Appearance sections use fresh shared factories so each tab has independent button state and the same command arrangement.

AR no longer has a workspace or tab. Home, Assemble, Render, and Animate expose a Share section with AR Export and Stop Sharing. The old `ar` workspace identifier resolves to Design for existing callers and saved preferences.

Move stays visible. Rotate, Scale, Mirror, and Duplicate use the same menu on all modeling ribbons, including Mesh and ECAD. Solid creation groups primitives and features, all five pattern methods share a menu, and specialist groups use compact flat menus. Assembly positioning and contextual sketch actions retain their distinct semantics. User-authored ribbon layouts are still honored; resetting a customized tab adopts the new shipped defaults.

## Site maintenance

The VitePress site is in `site`. Its searchable catalog is generated by `tools/Prism.DocsCatalog` from the actual default ribbon/workspace model. The catalog carries a source digest, the site build checks freshness in the CAD checkout, and the docs workflow compares regenerated data. Narrative guides and the changelog remain editable Markdown.

Hosting identity is saved in `site/.openai/hosting.json`. Only the website source is synchronized to its separate hosting repository; the CAD source remains in this repository. The website is owner-private. Public installer releases have not been published.

Verified live URL: https://prism-cad-guide.christopherbfwilliam.chatgpt.site

## Packaging

The packaging script builds a self-contained desktop app and MCP bridge, stages native dependencies and license notices, and creates Windows setup, macOS DMG, or Linux DEB artifacts on the matching host. Each package gets a SHA256 sidecar. Windows includes its required C++ runtime files and optional desktop shortcut. Uninstall uses an exact file manifest and preserves user-added files.

The application has a `--verify-runtime` mode that creates exact geometry and a tetrahedral mesh, allowing release builds to verify both native shims without opening a UI. Packaged MCP discovery uses its executable directly and can locate the installed desktop executable.
