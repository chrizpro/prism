# Right-hand studio panel concepts

Generated using the built-in image generation tool. These are visual concepts, not implemented panels.

## Existing functionality audit

- Appearance studio: substantial overlap with `Prism/Views/MaterialsPanel.axaml` and `Prism/ViewModels/MainViewModel.Materials.cs`. Existing controls already cover material browsing/assignment, swatches, hexadecimal color, metallic/gloss sliders, surface finish, pattern size, grain angle, engineering data and comparison. The proposal reorganizes that functionality rather than introducing another materials system. Thumbnail swatches are a visual enhancement.
- Diagnostics: partial overlap with sketch solver status and constraints in `Prism/Views/SketchPanel.axaml`, active command errors in `Prism/Views/CommandPanel.axaml`, and session messages/logs and rebuild failures in `Prism/Core/CadSession.cs`. No unified document issues/repair panel was found in the inspected Views, ViewModels and Controls. The proposal consolidates existing feedback; additional document checks would require implementation.
- References: substantial overlap with Origin, Planes, Sketches, Curves and Construction Planes in `Prism/ViewModels/MainViewModel.Browser.cs`. The proposal is a focused reference manager over the same geometry. Dependency listings and richer reference editing are proposed extensions.
- Parameters: individual command numeric fields and sketch dimensions already exist. `Prism/Core/Expression.cs` parses equation curves; it is not a document-wide named-parameter dependency system. No global named parameter/formula studio was found in the inspected code. The Document parameters tab, expressions, pinned values and automatic dependency binding shown here are proposed functionality.
