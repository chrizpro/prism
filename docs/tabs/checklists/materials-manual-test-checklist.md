# Materials manual test checklist

See the [feature guide](../../appearance-studio/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Assign two visibly different finishes to separate bodies. Confirm each applies only to its intended body.
- [ ] Use Find Assigned or Compare to identify which material is on each part, then clear the comparison.
- [ ] Save and reopen to confirm the finishes persist. Remove one assignment and check that the other body keeps its finish.
