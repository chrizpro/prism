# Drawing manual test checklist

See the [feature guide](../../drawing/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Create a sheet and place a base view and a projected view of a known-size model. Verify orientation and scale.
- [ ] Add a dimension and an annotation. Change the model, update the drawing, and check the affected views and dimensions.
- [ ] Save and reopen the project, then export a PDF. Compare the exported sheet and its visible annotations with the drawing in Prism.
