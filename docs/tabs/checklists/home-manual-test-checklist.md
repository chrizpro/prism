# Home manual test checklist

See the [feature guide](../../interface/gallery/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Open a gallery model and confirm its bodies appear in the browser and viewport. Save a copy and reopen the gallery entry to check that it starts fresh.
- [ ] Create a box, switch between Object and Face selection, and verify the browser and viewport agree on what is selected.
- [ ] Move the box by a known distance, measure the shift, and confirm Undo restores its original position.
