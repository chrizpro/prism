# Predictable ribbons

Prism organizes tools by task, then uses a shared order for the sections that appear across ribbons.

## The common sequence

**Select → References → Create → Modify → Combine → Transform → Pattern → Inspect → Appearance → Share**

Not every ribbon needs every section. Specialized sections such as Supports, Loads, or Surface Continuity appear at the appropriate point in the workflow. Shared sections retain their relative order throughout the application.

## Compact groups

Move stays directly accessible. Rotate, Scale, Mirror, and Duplicate share the same transform menu across modeling ribbons, including Mesh and ECAD. Pattern methods live together, and related operations use flat menus rather than nested menus.

Ribbon overflow arrows keep tools reachable when the window is narrow. Command search also finds individual tools inside grouped menus.

## Personal layouts

Settings still lets you customize, hide, or reset ribbons. The shared layout policy controls the shipped defaults; it does not overwrite your saved custom layouts. Reset a modified tab if you want it to adopt the new default arrangement.

## AR has moved

AR Export and Stop Sharing are under **Share → AR & sharing** on **Home**, **Assemble**, **Render**, and **Animate**. There is no separate AR workspace or AR ribbon.
