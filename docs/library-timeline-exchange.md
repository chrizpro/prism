# Parts library, animation timeline, tab previews and file exchange

## Tab previews
Hover an open-document tab to see a thumbnail of the viewport as you last left it, plus the object count and whether it has unsaved changes. The thumbnail is taken when you switch away from a tab; the tab you are on shows only its title.

## Parts library
Assemble > Components > **Parts Library** opens a picture grid in the right panel.

- **Choose folder…** points it at a folder of STEP (`.step`, `.stp`) and Prism (`.prism`) files. Sub-folders become categories. The folder is remembered; **↻** rescans.
- Thumbnails are drawn by a small built-in renderer and cached in `%LOCALAPPDATA%\Prism\library-cache`, so a folder opens quickly the second time.
- Double-click a part (or **Insert selected part…**) to place it as a component. The first component is grounded. `.prism` parts stay linked to their file (Refresh updates them); STEP parts are embedded copies.
- **Built-in common parts** need no files: ISO metric hex nuts, flat washers, hex bolts and socket-head screws M3-M12, dowel pins, round spacers, ball bearings, square tubes and primitives. They are generated by the kernel, so they work offline. Hide them with the checkbox.
- An empty folder is fine; the built-in parts are still listed.

The startup [Made with Prism gallery](interface/gallery/README.md) downloads curated native examples and opens editable document copies. It is separate from inserting a local part as an assembly component.

Observed 2026-11-05: local part extraction and saved thumbnails currently include only visible Solid/Surface BREP objects. Freeform-only parts cannot be extracted, and mixed examples such as the [Cove chair](../gallery/models/cove-chair.prism) omit their cages from the part thumbnail/component geometry. [Bug #62](https://github.com/chrizpro/prism/issues/62) tracks this limitation and the unresolved component-representation decision. The startup gallery opens complete native documents and retains the cages.

## Animation timeline
While the Animation command is open (Assemble > Edit / Play) a timeline docks above the design history. The right-hand panel keeps the joint values, exploded view, length, loop and ease options.

- One row per joint value and one for the exploded view; keys are diamonds, the blue bar spans a row's first to last key.
- Click or drag the ruler (or anywhere in the track area) to scrub. Drag a diamond to retime it (snaps to 0.05 s, hold Alt for free). Double-click an empty spot in a row to add a key holding the current value there. Select a diamond and press Delete to remove it.
- Space plays and stops, Home/End jump to the ends, arrow keys nudge by 0.1 s.
- The toolbar has Play/Stop, back to start, **Key changed values** (change joint values in the panel, then key them at the playhead) and **Remove keys here**.
- The key at 0 s is the starting pose and stays put.

## File exchange (File tab > Exchange)
| Format | Import | Export |
|---|---|---|
| STEP `.step` `.stp` | yes | yes |
| IGES `.iges` `.igs` | yes | yes (solids as BREP entities) |
| BREP `.brep` | yes | yes |
| DXF `.dxf` | LINE, CIRCLE, ARC, LWPOLYLINE, POLYLINE into a sketch on XY | sketches as LINE / CIRCLE / ARC (ellipses and splines as polylines), one layer per drawing plane |
| STL, OBJ, PLY, 3MF | yes | yes |
| glTF `.glb` | no | yes (Y-up, metres, one colour per body) |
| Drawings | | SVG, PDF, DXF (Analyze > Make Drawing) |

**Import File** picks the importer from the extension. The MCP `file` tool has the same actions (`import_file`, `export_iges`, `export_brep`, `export_glb`, `export_dxf`).

Not yet: glTF import, 3D DXF, proprietary native CAD files, SAT, Parasolid, USD, SVG import, colours and assembly structure in STEP.
