## Behavior

- Home shows **Made with Prism** with image cards, workflow/category, description, and a credit line noting the example was made with Prism MCP alongside its author and license. The section text links the examples to the same MCP toolkit configurable in Settings → AI Assistant. Search matches names, descriptions and workflow. Existing workspace, recent files and new/open actions remain available.
- Cards are grouped into titled sections by the workflows in a model's Workflow field, in the order of the workspace tabs: Solid, Surface, Freeform, NURBS, Sheet Metal, Assembly, CAM, Mold, CAE, ECAD (a workflow outside these gets its own section after them; empty sections are hidden). A model is listed under **every** workflow it names, so `CAE / Solid` appears in both sections. Each section shows its first three models, in catalog order, with **Show all N** / **Show fewer**; the expanded state lasts while Home is open. Searching shows every match, grouped, without the limit. *Owner direction 2026-11-08 ([#84](https://github.com/chrizpro/prism/issues/84)); the order, the three-model limit and listing under every workflow are the owner's choices (Assembly was added as a tab-named section).* Tests: GAL-U007, GAL-H003.
- A model that has **extra files** (an animation video, an exploded view image) shows its action as a split button: the main button still downloads and opens the model, and its dropdown offers *Download animation video (MP4)* or *Download exploded view (PNG)*. Extras are listed in the catalog entry's optional `Extras` (label, file name, URL, size, SHA-256), hosted in `gallery/extras/` on GitHub like models, verified on download, and saved to the workspace's `Gallery` folder under a new name, never overwriting a file. The card displays progress, errors and the full, selectable saved path beside its download control. With the default workspace on Windows, look in `Documents\Prism\Gallery`. *Owner request 2026-11-08 ([#84](https://github.com/chrizpro/prism/issues/84)).* Tests: GAL-U008. The Meridian orrery offers its drive animation and an exploded view.
- **Opens ready to work.** A saved document remembers the ribbon tab it was last used on and reopens there, with its saved studies, CAM setups and toolpaths, and render settings already in place, so a gallery model that was saved on the CAE, CAM or Assembly tab opens in front of that tab and the user only has to press Run or Play. Study *results* are not stored (they are recomputed), and a command is not left open. *Owner direction 2026-11-08 ([#85](https://github.com/chrizpro/prism/issues/85)): the less friction for a new user, the better.* Test: GAL-H004. A file can also leave a command open: its saved **opening command** is started after the tab is selected, so the Meridian orrery opens on Assemble with Drive Joints open and the serving board opens on the CAM tab with Playback open, and the user only presses the command's button; the wrench opens on Static with its study ready to Run. Scripts set both with the `select_tab` tool (`title`, optional `command`). Test: GAL-H006. A command that needs a selection or a running solver is not left running, only open.
- Only the small catalog ships with Prism. Models and previews live in the public repository's `gallery/` directory, outside application assets and packaging. Small initial files use GitHub raw downloads; the catalog also supports GitHub Release asset URLs for larger collections later.
- Home loads the local catalog immediately and refreshes the remote catalog/previews asynchronously. Failure never blocks startup; Refresh retries. Last valid catalog and previews remain available offline. A first offline launch shows catalog text and preview placeholders.
- A card downloads its model only on request, checks size and SHA-256, and atomically caches the verified file. Cached models work offline. A newer content hash gets a separate cache entry.
- Opening always creates a uniquely named editable copy under the workspace's `Gallery` folder (or Documents/Prism/Gallery when no workspace is selected). Cache files and previous working copies are never overwritten. Saving edits cannot alter the downloadable original.
- Catalog entries include stable ID, workflow, author, license, minimum Prism version, HTTPS model/preview URLs, model size and SHA-256. Unsupported newer minimum versions cannot open. Catalog schema errors retain the prior catalog. Downloads are bounded and time out; partial/corrupt downloads are not offered as cached models.
- Curated examples are concept studies. Geometry and appearance are retained in native files; older studies may lack construction history. The Surface pendant retains its hidden meridian and source surface; the Freeform chair retains editable cages. Reproducible scripts are linked from the content README.

A bend zone must be a clean rectangle of metal, so the petals are rectangles through both bends and the trapezoids sit beyond the second one; slanted edges crossing a zone would make Fold refuse the bend. The script derives the signed angle of each bend in Fold's own order (left to right, then bottom to top) and checks that the folded volume equals t × (flat area − bend zones) + the bend sectors, and that the flat pattern keeps all 17 holes. Building it exposed a Fold bug, fixed in the same change: a bend line was not truly infinite, because its cutting strip was centered on the line's first drawn point, so lines drawn far from the sheet cut only part of it and Fold said the bends did not divide the outline (FLD-H014). [GAL-I008](../../../Prism.Tests/Integration/DesktopGalleryTests.cs) checks the volume and hole count against the flat pattern.
