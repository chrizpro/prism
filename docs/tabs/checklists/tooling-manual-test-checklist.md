# Mold inspection checklist (formerly Tooling)

These tools now live in **Mold → Inspect**. Tooling has been removed as a separate ribbon tab.

See the [feature guide](../../modeling/mold/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Run Draft Analysis on a part with a known pull direction and tapered face. Reverse the direction and compare the face colors.
- [ ] Use Section Analysis across a cavity and check that the visible cross-section matches the selected plane.
- [ ] Run Check Geometry on both mold halves and identify which body any reported issue belongs to.
