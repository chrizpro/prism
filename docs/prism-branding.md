# Prism naming and identity

The checkout folder is `Prism`, and Rider opens `Prism.slnx`. The Codex project record uses Prism and points to the same folder; its sidebar cache refreshes when Codex restarts. Old build outputs and IDE metadata have been moved outside the checkout; managed outputs rebuild using the current names and location. A native CMake build directory must be configured again after relocating the checkout because CMake caches absolute paths.

The desktop executable does not emit a reference assembly because no project references it. This avoids a reproducible Avalonia build failure when rewriting the executable's intermediate reference assembly after a fresh build.

The solution, managed projects, namespaces, native library targets, automation bridge, environment variables, document extension, and platform display names use Prism. New documents use `.prism`; `.ourcad` remains an explicit compatibility extension.

The faceted triangular prism mark uses ice cyan `#B5F2FF`, cyan `#39C8ED`, blue `#4088ED`, violet `#7762ED`, and slate `#142338`. The PNG and SVG sources, Windows ICO, Android launcher and splash assets, browser favicon, and iOS app icon are generated by `tools/generate_prism_brand.py`. The home screen and main header use the same mark.

Code comments and Markdown documentation describe Prism's behavior without competitor comparisons or claims of feature parity. Underlying geometry APIs, mathematical names, library dependencies, and technical solver references retain their proper names. For example, Open CASCADE's `Precision::Confusion()` is a geometry tolerance API and is unrelated to another CAD application.
