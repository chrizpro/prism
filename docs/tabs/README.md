# Ribbon tab guides

One page per ribbon tab: what each section is for, what every tool does, and where it could improve.

| Tab | Guide |
|---|---|
| Direct Modeling | [direct-modeling/README.md](direct-modeling/README.md) |

The other tabs (Home, Solid, Surface, NURBS, Freeform, Sheet Metal, Mesh, ECAD and the rest) do not have a guide yet. Each page follows the same shape: the sections left to right with their intent, a table of tools with a status (Done, Thin, Gap) and improvement notes, then known gaps and suggested next steps.
