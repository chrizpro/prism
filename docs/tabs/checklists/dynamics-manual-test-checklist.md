# Dynamics manual test checklist

See the [feature guide](../../cae-studies/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Assign a material and constrain one end of a beam. Run Natural Frequencies and inspect the first mode.
- [ ] Confirm the fixed end stays fixed in the mode display. Change the support or material and rerun to check that the result changes.
- [ ] After solving, click Show Mode on the ribbon. Confirm the Results section opens, choose a returned mode and display it.
- [ ] Recall the saved setup and verify the selected faces before solving again.
