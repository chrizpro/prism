# Tool assistance

Hover help and active-tool guidance have separate jobs and locations.

- **Hover a ribbon button:** after a short delay, a tooltip opens beside the pointer. Extrude, Loft, Sweep and Revolve (including Surface variants), Fillet, Chamfer, CAE Fixed Support, Force and Pressure, and CAM Profile and Pocket show examples. CAM paths are generated by the commands; CAE face highlights illustrate selections rather than solved results. Other tools show their ordinary description. Dropdown variants use the same behavior.
- **Learn More:** every tool tooltip has this hyperlink, regardless of whether it has an in-app example. Until the website is published it shows “Online tool guides are coming soon.” Configure `ToolDocumentationBaseUrl` with the future per-tool guide base URL; links append the escaped stable tool ID.
- Disabled ribbon commands and disabled dropdown options can still show hover help; they cannot be run until their usual requirements are met.
- **Activate a tool:** the top-right viewport assistance shows the current instruction. It updates as inputs are chosen, when the active selection slot changes, or when a tool enters a temporary operation step. Sketch tools use their current drawing prompt. Hovering another tool leaves this guidance and the active operation untouched.
- **Dismiss:** leave the tool and tooltip to close hover help, or press Esc. F1, right-click **Show tool example**, and the command panel's **Show tool example** open the same tooltip. These never add example geometry to the viewport.

The examples use isolated OpenCascade shapes and the existing mesh renderer. They never add scene objects, move the working camera, or create undo history. The active command's own geometry preview continues to show the result of the user's selections.

`Prism/Help/ToolHelp.cs` holds the examples. Match command types as well as icons: Sweep 2 rails shares the Sweep Surface icon but needs different instructions. `MainViewModel.ToolHelp.cs` supplies live instructions; the ribbon owns hover tooltips.

Run `dotnet run --project tests/Prism.ToolHelpTests` from the repository root. Checks cover the kernel examples, pointer placement, images in both themes, documentation links, hover isolation, live selection steps, and dismissal. Screenshots are written to `artifacts/tool-help-review`.
