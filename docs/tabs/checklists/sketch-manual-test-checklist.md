# Sketch manual test checklist

See the [feature guide](../../modeling/sketches/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Draw a closed rectangle and add width and height dimensions. Change one dimension and measure the updated profile.
- [ ] Project an edge from existing geometry. Confirm the projected and construction lines behave as expected when selecting an extrusion profile.
- [ ] Finish the sketch and extrude the closed region. In a second edit, use Cancel and confirm the uncommitted changes are discarded.
