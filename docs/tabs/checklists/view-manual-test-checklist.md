# View manual test checklist

See the [feature guide](../../interface/view-home/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Switch among front, top, and isometric views. Check camera orientation against a model with visibly different sides.
- [ ] Use Hide, Isolate, then Show All on a multi-body model. Confirm only the intended bodies remain visible at each step.
- [ ] Switch to Two Views and try Link Views. Verify the expected camera relationship, then clear an active section.
