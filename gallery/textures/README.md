# Walnut valet texture

`walnut-valet-color.png` is an original AI-generated diffuse bitmap created with the built-in imagegen tool for the owner-approved #131 demo. It is embedded in `walnut-valet.prism`; the native model needs no external texture files.

Generation prompt (built-in imagegen):

> Use case: product-mockup. Asset type: original diffuse color bitmap texture for CNC walnut tray CAD material. Generate a flat orthographic straight-on scan of a beautiful uninterrupted solid American black walnut wood surface, filling every pixel. Warm rich medium brown, dark flowing fine grain, elongated subtle cathedral grain along horizontal X direction, natural variation with one or two small subdued knots, premium oiled walnut color but NO specular highlights. Perfectly uniform diffuse illumination. No object outline, no board edges, no plank seams, no gaps, no bevels, no perspective, no shadows, no vignette, no labels, no text, no tools. This is a material albedo texture map, not a product image. Landscape 3:2 composition. Moderately fine detailed wood pores, believable irregular organic grain, avoid excessive swirls, avoid orange color. Full bleed continuous wood.


The gallery preview is an actual Prism render of native geometry, not the concept image. Appearance is a visual study; grain placement uses blended box projection rather than topology-aware wood fibers or separate end-grain mapping.

`walnut-pavilion-512.jpg` is a 512-pixel JPEG derivative of that same original bitmap. It is embedded in the observatory roofs, Art Deco clock case and guitar back to retain visible wood grain without repeating a multi-megabyte image in each modeling-history snapshot. These three wood studies are tracked in [#132](https://github.com/chrizpro/prism/issues/132); their scope is native modeling without rendering or CAM setup.

# Serein display artwork

`serein-display.png` is original procedural abstract ribbon artwork generated by the `wallpaper()` function in [build_serein_phone.py](../build_serein_phone.py), using NumPy and Pillow. It uses no external source image or generative-image service. The bitmap is embedded in the native phone's planar display appearance; the clock, date and gesture indicator are separate native solids. The screenshot evidence is actual Prism output. Phone scope: [#137](https://github.com/chrizpro/prism/issues/137).
