# Freeform manual test checklist

See the [feature guide](../../modeling/freeform/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Start with a freeform box. Enter Edit Freeform, move a cage face, and confirm the smooth preview follows the cage.
- [ ] Insert a loop and add a crease. Compare the result before and after, then run Check Cage.
- [ ] Convert a simple closed form to NURBS and compare the visible outline and dimensions with the source.
