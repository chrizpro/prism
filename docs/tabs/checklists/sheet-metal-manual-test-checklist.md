# Sheet Metal manual test checklist

See the [feature guide](../../modeling/sheet-metal/README.md). Record the Prism build and any result that differs from the expected behavior.

- [ ] Make a simple flange from a closed sketch. Measure the thickness, then add an edge flange with a known bend angle.
- [ ] Add a cut-out and create a flat pattern. Check that the cut-out and bend lines appear in the expected locations.
- [ ] Change a bend setting and recreate the flat pattern. Compare the blank dimensions with the earlier version.
